# Task: Map Editor Auto-Upload Integration

## Description

Implement dedicated auto-upload endpoint for map editor integration that allows the map editor to automatically upload JSON files when users export their map configurations. This endpoint operates asynchronously (fire-and-forget) to avoid blocking the editor's export functionality.

## Acceptance Criteria

- [ ] Auto-upload handler implemented in `autoUploadHandler.go`
- [ ] Auto-upload usecase implemented with async/non-blocking logic
- [ ] Endpoint registered at `POST /api/filestorage/:projectId/map/auto-upload`
- [ ] Endpoint accepts JSON file upload
- [ ] Versioning automatically applied to uploaded files
- [ ] Upload executes asynchronously without blocking response
- [ ] Errors logged but not returned to client (fire-and-forget)
- [ ] Success response returned immediately
- [ ] Swagger documentation added for endpoint
- [ ] Integration tested with map editor team
- [ ] Documentation created for map editor integration

## Technical Details

### Auto-Upload Handler

**Handler Implementation** (`handler/autoUploadHandler.go`):
```go
type AutoUploadHandler struct {
    UseCase IAutoUploadUseCase
}

func NewAutoUploadHandler(c *echo.Echo, useCase IAutoUploadUseCase) IAutoUploadHandler {
    handler := &AutoUploadHandler{UseCase: useCase}

    // Auto-upload endpoint for map editor
    c.POST("/api/filestorage/:projectId/map/auto-upload", handler.AutoUpload)

    return handler
}

// AutoUpload handles async file upload from map editor
// @Router /api/filestorage/{projectId}/map/auto-upload [post]
// @Summary Auto-upload map JSON from map editor
// @Description Asynchronously uploads map JSON file when user exports from map editor
// @Accept multipart/form-data
// @Produce json
// @Param projectId path string true "Project ID"
// @Param file formData file true "Map JSON file"
// @Success 202 {object} map[string]interface{} "Upload initiated"
// @Failure 400 {object} map[string]interface{}
// @Tags filestorage
func (h *AutoUploadHandler) AutoUpload(c echo.Context) error {
    ctx, _, _ := common.CtxGenerate(c)

    projectID := c.Param("projectId")
    if projectID == "" {
        return c.JSON(http.StatusBadRequest, map[string]interface{}{
            "success": false,
            "message": "projectId is required",
        })
    }

    // Parse multipart form
    form, err := c.MultipartForm()
    if err != nil {
        return c.JSON(http.StatusBadRequest, map[string]interface{}{
            "success": false,
            "message": "Failed to parse form data",
        })
    }

    // Get file
    files := form.File["file"]
    if len(files) == 0 {
        return c.JSON(http.StatusBadRequest, map[string]interface{}{
            "success": false,
            "message": "No file provided",
        })
    }

    file := files[0]

    // Validate file type (optional - can skip per PRD)
    if !strings.HasSuffix(file.Filename, ".json") {
        // Log warning but continue (no validation per PRD)
        log.Printf("Warning: Non-JSON file uploaded to map auto-upload: %s", file.Filename)
    }

    // Launch async upload (fire-and-forget)
    go func() {
        // Use background context to avoid cancellation
        bgCtx := context.Background()

        if err := h.UseCase.AutoUpload(bgCtx, projectID, file); err != nil {
            // Log error but don't propagate to client
            log.Printf("Auto-upload failed for project %s: %v", projectID, err)
        } else {
            log.Printf("Auto-upload successful for project %s: %s", projectID, file.Filename)
        }
    }()

    // Return immediate success response (202 Accepted)
    return c.JSON(http.StatusAccepted, map[string]interface{}{
        "success": true,
        "message": "Upload initiated",
        "data": map[string]string{
            "project_id": projectID,
            "filename":   file.Filename,
        },
    })
}
```

### Auto-Upload UseCase

**UseCase Implementation** (`usecase/autoUploadUseCase.go`):
```go
type AutoUploadUseCase struct {
    Repository     IFileStorageRepository
    ContextTimeout time.Duration
}

func NewAutoUploadUseCase(repo IFileStorageRepository, timeout time.Duration) IAutoUploadUseCase {
    return &AutoUploadUseCase{
        Repository:     repo,
        ContextTimeout: timeout,
    }
}

// AutoUpload handles async upload with versioning
func (u *AutoUploadUseCase) AutoUpload(
    ctx context.Context,
    projectID string,
    fileHeader *multipart.FileHeader,
) error {
    ctx, cancel := context.WithTimeout(ctx, u.ContextTimeout)
    defer cancel()

    // Open file
    file, err := fileHeader.Open()
    if err != nil {
        return fmt.Errorf("failed to open file: %w", err)
    }
    defer file.Close()

    // Generate versioned filename
    versionedName := versioning.GenerateVersionedFilename(fileHeader.Filename)

    // Save file with versioning
    if err := u.Repository.SaveFile(projectID, "map", versionedName, file); err != nil {
        return fmt.Errorf("failed to save file: %w", err)
    }

    // Log success
    log.Printf("Auto-uploaded file: %s -> %s", fileHeader.Filename, versionedName)

    return nil
}
```

### Integration with Map Editor

**Map Editor Side Implementation** (for documentation):

The map editor should call the auto-upload endpoint after generating the JSON export:

```typescript
// Map editor export function
async function exportMap(projectId: string, mapData: any) {
  // Generate JSON
  const jsonBlob = new Blob([JSON.stringify(mapData)], {
    type: 'application/json'
  });

  // Create form data
  const formData = new FormData();
  formData.append('file', jsonBlob, 'parking_map.json');

  // Trigger auto-upload (fire-and-forget)
  try {
    await fetch(`/api/filestorage/${projectId}/map/auto-upload`, {
      method: 'POST',
      body: formData,
    });
    // Don't wait for completion or check response
  } catch (error) {
    // Silently log error, don't block export
    console.warn('Auto-upload failed:', error);
  }

  // Continue with normal export flow
  downloadJsonToUser(jsonBlob);
}
```

### Error Handling Strategy

**Fire-and-Forget Pattern**:
1. Endpoint returns 202 Accepted immediately
2. Actual upload happens in background goroutine
3. Errors logged to server logs, not returned to client
4. Map editor doesn't wait for upload completion
5. User can manually upload if auto-upload fails

**Logging**:
```go
// Success log
log.Printf("[AUTO-UPLOAD] SUCCESS: project=%s, file=%s, version=%s",
    projectID, originalName, version)

// Error log
log.Printf("[AUTO-UPLOAD] ERROR: project=%s, file=%s, error=%v",
    projectID, filename, err)
```

### Concurrent Upload Handling

**Conflict Resolution**:
- Last write wins (per PRD decision)
- No lock mechanism needed
- Timestamp-based versioning prevents overwrites
- Multiple simultaneous uploads create separate versions

Example scenario:
1. User exports from map editor → auto-upload creates `map_1698765432.json`
2. User manually uploads via UI → creates `map_1698765440.json`
3. Both versions preserved, latest timestamp is current version

## Integration Documentation

### For Map Editor Team

**Endpoint Details**:
- **URL**: `POST /api/filestorage/{projectId}/map/auto-upload`
- **Method**: POST
- **Content-Type**: multipart/form-data
- **Body**: Single file with key "file"
- **Response**: 202 Accepted (immediate)

**Integration Steps**:
1. After user clicks "Export" in map editor
2. Generate map JSON data
3. Create FormData with JSON file
4. POST to auto-upload endpoint
5. Don't wait for response or check errors
6. Continue with normal export flow

**Error Handling**:
- Ignore any errors from auto-upload
- User can manually upload via file storage UI if needed
- Auto-upload is a convenience feature, not critical path

**Example Code**:
```javascript
// After map export
const formData = new FormData();
formData.append('file', jsonBlob, 'parking_map.json');

fetch(`/api/filestorage/${projectId}/map/auto-upload`, {
  method: 'POST',
  body: formData,
}).catch(err => console.warn('Auto-upload failed:', err));
```

## Notes

- Use `go func()` for async execution (goroutine)
- Use background context to avoid cancellation when request ends
- Return 202 Accepted (not 200 OK) to indicate async processing
- Don't propagate errors to client (fire-and-forget pattern)
- Log all auto-upload attempts for debugging
- Coordinate with map editor team for integration timeline
- Auto-upload is optional feature - system works without it
- Consider rate limiting if abuse becomes issue (future enhancement)
