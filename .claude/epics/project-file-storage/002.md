### Generic Handler Implementation

**File Storage Handler** (`handler/fileStorageHandler.go`):
```go
type FileStorageHandler struct {
    UseCase IFileStorageUseCase
}

// NewFileStorageHandler registers all routes
func NewFileStorageHandler(c *echo.Echo, useCase IFileStorageUseCase) IFileStorageHandler {
    handler := &FileStorageHandler{UseCase: useCase}

    // Upload endpoints
    c.POST("/api/filestorage/:projectId/map/upload", handler.Upload)
    c.POST("/api/filestorage/:projectId/cad/upload", handler.Upload)
    c.POST("/api/filestorage/:projectId/roi/upload", handler.Upload)
    c.POST("/api/filestorage/:projectId/learning/upload", handler.Upload)
    c.POST("/api/filestorage/:projectId/test/upload", handler.Upload)

    // List endpoints
    c.GET("/api/filestorage/:projectId/map/list", handler.List)
    c.GET("/api/filestorage/:projectId/cad/list", handler.List)
    c.GET("/api/filestorage/:projectId/roi/list", handler.List)
    c.GET("/api/filestorage/:projectId/learning/list", handler.List)
    c.GET("/api/filestorage/:projectId/test/list", handler.List)

    // Download endpoints
    c.GET("/api/filestorage/:projectId/:category/download/:filename", handler.Download)
    c.GET("/api/filestorage/:projectId/:category/latest", handler.DownloadLatest)

    return handler
}

// Upload handles file upload for any category
func (h *FileStorageHandler) Upload(c echo.Context) error

// List returns file list for a category
func (h *FileStorageHandler) List(c echo.Context) error

// Download streams file content
func (h *FileStorageHandler) Download(c echo.Context) error

// DownloadLatest streams latest version of versioned file
func (h *FileStorageHandler) DownloadLatest(c echo.Context) error
```

### API Endpoint Details

#### Upload Endpoints
**Request**: `POST /api/filestorage/:projectId/{category}/upload`
- **Body**: multipart/form-data with key "files"
- **Response**:
```json
{
  "success": true,
  "message": "Files uploaded successfully",
  "data": {
    "total_files": 10,
    "success_count": 10,
    "failed_count": 0,
    "version": "1698765432",
    "uploaded_files": [
      {
        "filename": "parking_map_1698765432.json",
        "original_name": "parking_map.json",
        "path": "shared/banpo/map/parking_map_1698765432.json",
        "size_bytes": 45678
      }
    ]
  }
}
```

#### List Endpoints
**Request**: `GET /api/filestorage/:projectId/{category}/list?cctv_id={id}&page=1&page_size=100`
- **Query Params**:
  - `cctv_id` (optional): Filter by CCTV ID (for learning/test only)
  - `page` (optional): Page number (default: 1)
  - `page_size` (optional): Items per page (default: 100)
- **Response**:
```json
{
  "success": true,
  "message": "Files retrieved successfully",
  "data": {
    "total_count": 3,
    "files": [
      {
        "filename": "parking_map_1698766123.json",
        "original_name": "parking_map.json",
        "version": "1698766123",
        "size_bytes": 45678,
        "upload_date": "2025-10-27T08:15:23Z",
        "file_type": "application/json",
        "cctv_id": null
      }
    ],
    "pagination": {
      "page": 1,
      "page_size": 100,
      "total_pages": 1
    }
  }
}
```

#### Download Endpoints
**Request**: `GET /api/filestorage/:projectId/{category}/download/{filename}`
- **Response**: File stream with appropriate Content-Type header
- **Headers**:
  - `Content-Type`: Detected MIME type
  - `Content-Disposition`: `attachment; filename="{filename}"`
  - `Content-Length`: File size in bytes

**Request**: `GET /api/filestorage/:projectId/{category}/latest?original_name={name}`
- **Response**: Latest version file stream (for versioned categories only)

cctvID := c.QueryParam("cctv_id")

files, err := useCase.ListFiles(ctx, FileQueryRequest{

**File Streaming**:
```go
// Stream file for download
fileReader, fileInfo, err := useCase.DownloadFile(ctx, projectID, category, filename)
defer fileReader.Close()

// Set headers
c.Response().Header().Set("Content-Type", fileInfo.MimeType)
c.Response().Header().Set("Content-Disposition", fmt.Sprintf("attachment; filename=\"%s\"", filename))
c.Response().Header().Set("Content-Length", strconv.FormatInt(fileInfo.Size, 10))

// Stream response
return c.Stream(http.StatusOK, fileInfo.MimeType, fileReader)
```
