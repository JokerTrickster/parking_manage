### Version History Testing

#### Test Suite 5: Version Management

**Multiple Upload Test**:
```
1. Upload parking_map.json (Version 1)
   → Verify parking_map_<timestamp1>.json created

2. Wait 1 second

3. Upload parking_map.json again (Version 2)
   → Verify parking_map_<timestamp2>.json created
   → Verify timestamp2 > timestamp1

4. Upload parking_map.json again (Version 3)
   → Verify parking_map_<timestamp3>.json created

5. List map files
   → Verify 3 versions listed
   → Verify sorted by date (newest first)

6. Download latest version
   → Verify Version 3 returned

7. Download specific version (Version 1)
   → Verify correct file returned
```

**Version Parsing Test**:
```go
// Test versioning utility functions
func TestVersionGeneration(t *testing.T) {
    // Test timestamp generation
    v1 := versioning.GenerateVersionedFilename("test.json")
    time.Sleep(1 * time.Second)
    v2 := versioning.GenerateVersionedFilename("test.json")

    // Verify different timestamps
    assert.NotEqual(t, v1, v2)

    // Test parsing
    orig, version, err := versioning.ParseVersionFromFilename(v1)
    assert.NoError(t, err)
    assert.Equal(t, "test.json", orig)
    assert.NotEmpty(t, version)
}
```
