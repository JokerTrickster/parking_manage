# Task: Backend Core Infrastructure Setup

## Description

Create the foundational backend infrastructure for the file storage system. This includes setting up the `filestorage` feature module structure, implementing versioning utilities, and creating the core repository and usecase layers following the existing codebase patterns.

This task establishes the base architecture that all other tasks depend on.

## Acceptance Criteria

- [ ] `backend/src/features/filestorage/` module structure created with all subdirectories
- [ ] Versioning utility functions implemented and tested (timestamp generation, filename parsing)
- [ ] Generic file storage repository created with save/list/read/delete operations
- [ ] Generic file storage usecase implemented with versioning support
- [ ] File category enum defined (map, cad, roi, learning, test)
- [ ] Request/response models created for upload, list, and download operations
- [ ] Code follows existing Go patterns (handler/usecase/repository/model structure)
- [ ] Unit tests written for versioning utilities (>80% coverage)

### Key Implementation Points

**Versioning Utility** (`util/versioning.go`):
```go
// GenerateVersionedFilename adds timestamp suffix to filename
// Example: "parking_map.json" -> "parking_map_1698765432.json"
func GenerateVersionedFilename(originalName string) string

// ParseVersionFromFilename extracts timestamp version from filename
// Returns: originalName, version, error
func ParseVersionFromFilename(versionedName string) (string, string, error)

// GetTimestamp returns current Unix timestamp as string
func GetTimestamp() string
```

**File Storage Repository** (`repository/fileStorageRepository.go`):
```go
type FileStorageRepository struct{}

// SaveFile saves file to filesystem at specified path
func (r *FileStorageRepository) SaveFile(projectID, category, filename string, file multipart.File) error

// ListFiles returns all files for a project category
func (r *FileStorageRepository) ListFiles(projectID, category string, filters map[string]string) ([]FileInfo, error)

// ReadFile returns file content as io.ReadCloser
func (r *FileStorageRepository) ReadFile(projectID, category, filename string) (io.ReadCloser, error)

// DeleteFile removes file from filesystem
func (r *FileStorageRepository) DeleteFile(projectID, category, filename string) error

// GetFileMetadata returns file info (size, modified date, etc.)
func (r *FileStorageRepository) GetFileMetadata(projectID, category, filename string) (FileInfo, error)
```

**File Storage UseCase** (`usecase/fileStorageUseCase.go`):
```go
type FileStorageUseCase struct {
    Repository IFileStorageRepository
    ContextTimeout time.Duration
}

// UploadFile handles file upload with optional versioning
func (u *FileStorageUseCase) UploadFile(ctx context.Context, req UploadRequest) (UploadResponse, error)

// ListFiles returns file list with metadata
func (u *FileStorageUseCase) ListFiles(ctx context.Context, req FileQueryRequest) (FileListResponse, error)

// DownloadFile retrieves file for download
func (u *FileStorageUseCase) DownloadFile(ctx context.Context, projectID, category, filename string) (io.ReadCloser, FileInfo, error)

// GetLatestVersion returns the most recent version of a file
func (u *FileStorageUseCase) GetLatestVersion(ctx context.Context, projectID, category, originalName string) (string, error)
```

**File Category Enum** (`model/entity/fileCategory.go`):
```go
type FileCategory string

const (
    CategoryMap      FileCategory = "map"
    CategoryCAD      FileCategory = "cad"
    CategoryROI      FileCategory = "roi"
    CategoryLearning FileCategory = "learning"
    CategoryTest     FileCategory = "test"
)

// IsVersioned returns true if category supports versioning
func (c FileCategory) IsVersioned() bool {
    return c == CategoryMap || c == CategoryCAD || c == CategoryROI
}

// GetBasePath returns filesystem base path for category
func (c FileCategory) GetBasePath(projectID string) string
```
