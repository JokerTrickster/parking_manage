## Description

Rebuild the file management system with categorized views for 5 distinct file types, providing intuitive navigation and mobile-optimized file operations for parking system administration.

## Background

Current file management is basic and doesn't provide proper categorization or mobile-friendly operations. Need comprehensive file repository with visual categorization, bulk operations, and mobile-responsive design.

## Acceptance Criteria

### File Type Categories
- **ROI JSON Files**: Configuration files for region-of-interest definitions
  - Visual preview of ROI boundaries
  - Validation status indicators
  - Quick edit functionality
- **Raw Map JSON**: Original parking lot mapping data
  - Metadata display (creation date, source)
  - Version history tracking
  - Export/download options
- **Processed Map JSON**: Algorithm-processed mapping data
  - Processing status and results
  - Comparison with raw data
  - Error/warning indicators
- **Learning Images**: Training dataset images
  - Thumbnail grid view
  - Batch selection and operations
  - Image metadata (size, date, tags)
- **Test Images**: Validation and testing images
  - Test result overlays
  - Performance metrics display
  - Comparison tools

### Mobile File Operations
- Touch-friendly file selection (checkboxes, swipe gestures)
- Responsive grid layouts for different screen sizes
- Mobile-optimized upload with progress indicators
- Swipe-to-delete and batch operations
- Image preview with pinch-to-zoom
- Sorting and filtering controls optimized for touch

### Technical Requirements
- Category-based navigation with tab/accordion interface
- File preview system with lazy loading
- Bulk operations (select all, delete multiple, download zip)
- Search and filter functionality within categories
- File metadata display and editing
- Progress indicators for upload/download operations

## Technical Implementation

### Component Architecture
```
FileRepository/
├── CategoryTabs/
│   ├── ROIFilesTab/
│   ├── RawMapTab/
│   ├── ProcessedMapTab/
│   ├── LearningImagesTab/
│   └── TestImagesTab/
├── FileGrid/
│   ├── FileCard/
│   ├── ThumbnailView/
│   └── DetailView/
├── BulkOperations/
├── FileUpload/
└── SearchFilter/
```

### API Integration
- GET `/api/files/:category` - Fetch files by category
- POST `/api/files/upload` - Upload files with category
- DELETE `/api/files/bulk` - Bulk delete operations
- GET `/api/files/:id/preview` - File preview/thumbnail
- PUT `/api/files/:id/metadata` - Update file metadata

### Mobile Optimizations
- Responsive breakpoints: 320px, 768px, 1024px
- Touch target size minimum 44px
- Swipe gestures for mobile navigation
- Optimized image loading for mobile bandwidth
- Offline support for recently viewed files
