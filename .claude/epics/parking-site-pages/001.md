## Overview
Implement a complete navigation system for the parking management application with six distinct pages, supporting both React Router for SPA navigation and responsive mobile-first design.

## Acceptance Criteria

### Core Navigation Features
- [ ] Six-page routing system implemented using React Router v6
- [ ] Navigation menu accessible from all pages with clear active state indicators
- [ ] Breadcrumb navigation for complex page hierarchies
- [ ] URL-based routing with proper history management
- [ ] 404 error page for invalid routes
- [ ] Navigation preserves application state during page transitions

### Page Structure
- [ ] **Dashboard**: Main overview page with parking statistics
- [ ] **Live Monitoring**: Real-time parking space monitoring interface
- [ ] **Map Editor**: Interactive parking lot map editing tool (placeholder)
- [ ] **Map Properties**: Parking lot configuration and properties (placeholder)
- [ ] **Settings**: System configuration and user preferences
- [ ] **Reports**: Analytics and reporting interface

### Responsive Design
- [ ] Mobile hamburger menu for screens < 768px
- [ ] Desktop horizontal navigation bar for screens >= 768px
- [ ] Touch-friendly navigation elements (44px minimum tap targets)
- [ ] Navigation adapts gracefully to different screen orientations
- [ ] Keyboard navigation support for accessibility

### Technical Requirements
- [ ] React Router v6 implementation with proper route guards
- [ ] TypeScript interfaces for all navigation components
- [ ] Navigation state management using React Context or Redux
- [ ] Lazy loading for page components to optimize bundle size
- [ ] Navigation analytics tracking (page views, navigation paths)

- Sanitize navigation parameters to prevent XSS
